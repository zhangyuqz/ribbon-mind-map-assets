# 思维导图插件 · 排版压力测试用例（Markdown 输入）

这些 .md 是渲染那批测试图所用的**输入文件**。除中文基准为你提供的官方示例外，
其余七份由程序按“计数单位”定标自动生成：汉字/假名等表意字符算 1 个单位，
两个拉丁字母算 1 个单位——用单位数而非字符数对齐量级，才能让各语种的排版
负担与中文基准（最大节点 2792 单位）真正可比。

句子内容为各语种真实短语拼接，仅供排版引擎压力测试，**无实际语义**；超长节点
由一句填充话重复堆叠而成（故有大段重复，是刻意为之），用来逼出兄弟节点贴框、
节点超宽、深层布局等只有大规模文档才会暴露的问题。

注：磁盘上留存的是**最终定标版**（即真正出图的那一版）。字符数比开发早期表格偏大，
是因为量级口径从“重复固定次数”改成了“按计数单位对齐”，属正常演进，内容与最终图配套。
